# 🧠 ReflectBot AI — Telegram-бот для ежедневной рефлексии

[![Python](https://img.shields.io/badge/Python-3.10+-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://www.python.org/)
[![OpenAI](https://img.shields.io/badge/OpenAI-API-412991?style=for-the-badge&logo=openai&logoColor=white)](https://openai.com/)
[![Telegram](https://img.shields.io/badge/Telegram-Bot-2CA5E0?style=for-the-badge&logo=telegram&logoColor=white)](https://core.telegram.org/bots)
[![License](https://img.shields.io/badge/License-MIT-yellow?style=for-the-badge)](LICENSE)

**ReflectBot AI** — это интеллектуальный Telegram-бот, который помогает пользователям вести ежедневный дневник эмоций, анализировать свой прогресс и получать персонализированные рекомендации с помощью искусственного интеллекта (GPT-4o-mini).

---

## ✨ Ключевые возможности

- 📝 **Пошаговая рефлексия** — бот задаёт 4 структурированных вопроса о прошедшем дне (успехи, трудности, эмоции, планы).
- 🤖 **AI-анализ и советы** — после завершения опроса нейросеть генерирует краткий итог и даёт тёплый, конкретный совет на завтра.
- 💬 **Режим свободных вопросов** — пользователь может задать любой вопрос, и бот мягко направит диалог в русло саморефлексии и самоанализа.
- 📊 **Сравнение прогресса** — команда `/analysis` сравнивает две последние рефлексии пользователя, выделяя изменения в эмоциональном фоне и прогрессе.
- 🧠 **Умное управление состоянием** — бот запоминает контекст диалога, позволяет пропускать вопросы (`/next`) и корректно обрабатывает прерывания.
- 🔒 **Безопасное хранение секретов** — все API-ключи вынесены в переменные окружения (`.env`).

---

## 🛠 Технологический стек

- **Язык:** Python 3.10+
- **Фреймворк бота:** `pyTelegramBotAPI` (telebot)
- **Искусственный интеллект:** `openai` (модель `gpt-4o-mini`)
- **Управление окружением:** `python-dotenv`
- **Структуры данных:** `collections.defaultdict`, `collections.deque` (для эффективного хранения истории с ограничением по длине)
- **Конфигурация:** Переменные окружения (`.env`)

##  Установка и запуск

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/aimeeXIII/reflect-bot-ai.git
cd reflect-bot-ai
```

### 2. Создайте и активируйте виртуальное окружение
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для macOS/Linux:
source venv/bin/activate
```

### 3. Установите зависимости
```bash
pip install -r requirements.txt
```

Если файла `requirements.txt` нет, установите зависимости вручную:
```bash
pip install pyTelegramBotAPI openai python-dotenv
```

### 4. Настройте переменные окружения
Создайте файл `.env` в корне проекта на основе `.env.example` и добавьте ваши ключи:
```env
TELEGRAM_TOKEN=ваш_токен_от_BotFather
OPENAI_API_KEY=ваш_ключ_от_OpenAI
```

⚠️ **Важно:** Никогда не коммитьте файл `.env` в репозиторий! Убедитесь, что он добавлен в `.gitignore`.

### 5. Запустите бота
```bash
python main.py
```

## 📖 Доступные команды

| Команда      | Описание                                                  |
| :----------- | :-------------------------------------------------------- |
| `/start`     | Начать новую сессию ежедневной рефлексии                  |
| `/next`      | Пропустить текущий вопрос (ответ будет сохранён как "—")  |
| `/question`  | Включить режим свободного диалога с AI-коучем             |
| `/cancel`    | Выйти из режима свободного диалога                        |
| `/analysis`  | Получить сравнительный анализ двух последних рефлексий    |
| `/help`      | Показать справку по командам                              |

## 🏗 Архитектура и особенности реализации

### Управление состоянием
Используется комбинация `defaultdict` и `deque(maxlen=2)` для хранения истории ответов. Это гарантирует, что память не будет переполняться — хранятся только 2 последние сессии для анализа.

### Нормализация данных
Функция `clean_answers` нормализует ввод пользователя, заменяя пустые ответы на тире, что улучшает качество промптов для OpenAI и предотвращает ошибки при генерации.

### UX/UI
Имитация набора текста (`send_chat_action`) создаёт ощущение живого общения и скрывает задержки при запросах к API (особенно важно при работе с GPT).

### Безопасность
Все чувствительные данные (токены, API-ключи) вынесены в `.env` и загружаются через `python-dotenv`. Это соответствует best practices индустрии и позволяет легко деплоить бота на любые серверы без изменения кода.
